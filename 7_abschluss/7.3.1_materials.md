# Nachgenutzte Materialien

Zur Erstellung dieser OER wurden Materialien anderer Autor:innen nachgenutzt .  
Die entsprechenden Lizenzhinweise finden Sie zum einen an der Stelle an der die jeweiligen Materialien eingebunden sind und zum anderen hier folgend in der Reihenfolge ihres Auftretens in der OER:

Kapitel [3. Datenbasis](datenbasis):
- Datensatz "Baumbestandsdaten" von <a href="https://odis-berlin.de/" class="external-link" target="_blank">Open Data Informationsstelle Berlin (ODIS)</a> unter <a href="https://www.govdata.de/dl-de/zero-2-0" class="external-link" target="_blank">Datenlizenz Deutschland - Zero - Version 2.0</a> via <a href="https://wfsexplorer.odis-berlin.de/?wfs=https%3A%2F%2Fgdi.berlin.de%2Fservices%2Fwfs%2Fbaumbestand" class="external-link" target="_blank">WFSExplorer</a>.

- Datensatz "Bezirksgrenzen" von <a href="https://odis-berlin.de/" class="external-link" target="_blank">Open Data Informationsstelle Berlin (ODIS)</a> unter <a href="https://www.govdata.de/dl-de/zero-2-0" class="external-link" target="_blank">Datenlizenz Deutschland - Zero - Version 2.0</a> via <a href="https://wfsexplorer.odis-berlin.de/?wfs=https%3A%2F%2Fgdi.berlin.de%2Fservices%2Fwfs%2Falkis_bezirke&layer=alkis_bezirke%3Abezirksgrenzen" class="external-link" target="_blank">WFSExplorer</a>.

- Datensatz "Bewässerungsdaten" / "Gieß den Kiez - Nutzungsdaten" von <a href="https://www.govdata.de/">GovData</a> unter <a href="https://creativecommons.org/publicdomain/zero/1.0/" class="external-link" target="_blank">CC Zero 1.0</a> via <a href="https://www.govdata.de/suche/daten/giess-den-kiez-nutzungsdaten" class="external-link" target="_blank">GovData</a>.

Alle Materialien, die nicht explizit als extern ausgewiesen sind, sind eigene Erstellungen. Dies bezieht sich vor allem auf Abbildungen.
