# Technische Voraussetzungen

Diese OER wurde wie alle Materialien des Datenkompetenzzentrums <a href="https://www.quadriga-dk.de/de/ressourcen" class="external-link" target="_blank">QUADRIGA</a> mit <a href="https://jupyterbook.org/en/stable/intro.html" class="external-link" target="_blank">Jupyter Book</a> erstellt. Ein Jupyter Book ist ein Open-Source-Tool, das Text und Codeblöcke darstellen kann. Dazu werden aus Markdown- und Jupyter-Notebook-Dateien HTML-Seiten erstellt. Der Code und dessen Ausgaben sind direkt eingebettet und der Code kann über Integrationen wie Binder oder Google Colab auch interaktiv ausgeführt werden.

In dieser OER lässt sich das Potential von Jupyter Books nicht vollständig nutzen. Zwar ist es möglich R Code auszuführen. Allerdings wird in dieser Lerneinheit über mehrere Kapitel hinweig ein Dashboard gebaut, sodass es notwendig ist, R Studio parallel zu dieser OER zu öffnen (s. Anleitung unten).

## Zugangswege

Wir bieten zwei verschiedene Zugangswege:

📘 Book-Only Mode: Im Browser lesen Sie unser interaktives Lehrbuch mit eingeschränkten Interaktionsmöglichkeiten. Dies erfordert keine Programmierkenntnisse oder Erfahrung mit Jupyter Notebooks. Parallel dazu können Sie mit R Shiny an der Umsetzung des Dashboards arbeiten. 

💻 Local Mode: Selbstverständlich können Sie die Lerneinheit auch lokal ausführen. Dazu können Sie sich die Dateien über <a href="https://github.com/quadriga-dk/Tabelle-Fallstudie-3" class="external-link" target="_blank">GitHub</a> herunterladen. Dies ermöglicht die Nutzung eigener Daten und umfassende Anpassungen.  

Um den in der OER vorhandenen Programmcode in R parallel zum Lesen des Jupyter Books in RStudio zu bearbeiten, müssen Sie sich R und RStudio installieren. 

## Installieren von R und RStudio

Um der Übungseinheit effektiv folgen zu können, installieren Sie bitte vorab **R**. Zudem benötigen Sie eine geeignete Entwicklungsumgebung. Hierfür bietet sich **RStudio** an. Die Programmiersprache **R** und **RStudio** können Sie direkt vom Entwickler bzw. Maintainer <a href="https://posit.co/download/rstudio-desktop/" class="external-link" target="_blank">Posit</a> beziehen.  

**Hinweis**  
Die Übungen sind auf der Basis von R 4.5.3 entwickelt worden und zur Nutzung von RStudio 2026.04.0 Build 526 über Windows konzipiert. Sollten Sie eine andere RStudio Version oder ein anderes Betriebssystem nutzen, können einige Funktionen eventuell variieren.

**RStudio besteht aus vier Hauptbereichen:**

**R Skript:**  
Im R Skript geben Sie Befehle ein, die **R** ausführen soll.
Um einen Befehl auszuführen, drücken Sie `Strg + Enter` (MacOS: `Command + Return`), um eine einzelne Zeile zu starten, oder markieren Sie den gewünschten Code-Abschnitt und drücken Sie erneut `Strg + Enter` (MacOS: `Command + Return`), um mehrere Zeilen gleichzeitig auszuführen. Alternativ können Sie den Run-App-Button in der oberen rechten Ecke des Skript-Fensters nutzen oder die Tastenkombination `Strg + Shift + S` (MacOS: `Shift + Command + S`) verwenden.
Ein Beispielbefehl ist das vorab eingetragene Skript, das automatisch beim Erstellen einer neuen Shiny-Web-App generiert wird.
Sie können das Skript speichern und später erneut öffnen. 

**Console:**  
Hier führen Sie Befehle direkt aus und bekommen deren Ergebnisse sowie eventuelle Fehlermeldungen angezeigt.

**Environment:**  
Dieser Bereich zeigt alle geladenen Objekte, Datensätze und Variablen an. Auch von Ihnen selbst erstellte Listen oder Datenframes werden hier verwaltet.  

**Dateien:**  
Hier können Sie Dateien anzeigen, verwalten und importieren. Zudem bietet dieser Bereich Ihnen Zugriff auf Verzeichnisse und gespeicherte Projekte.

**Web-App:**  
Ein weiteres Anzeigefenster ist die Web-App: Dieses öffnet sich, sobald Sie den dazugehörigen Befehl im R-Skript ausgeführt haben, automatisch.  In diesem Bereich wird die visuelle Ausgabe der Shiny-App dargestellt. Je nach Einstellung öffnet sich das Fenster entweder direkt in RStudio oder in einem externen Browser.
